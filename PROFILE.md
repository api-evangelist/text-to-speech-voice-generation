# ForgeMesh Voice

A live REST/HTTP text-to-speech and voice generation API (OpenAPI 3.1) for agents, apps, video narration, audiobooks, games, and alerts. Offers 20 voices (10 standard + 10 personas), expressive controls (speed, quality), 31 languages, and an OpenAI-compatible route. Agent-native access with no API keys or signup — pay-per-call via the x402 (HTTP 402) protocol using USDC on Base.
